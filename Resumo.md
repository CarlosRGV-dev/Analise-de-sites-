# Resumo – Aula 01: Apresentação da Disciplina e Introdução à Programação Web

## Objetivo da Aula
A primeira aula apresentou a disciplina de Programação Web, seus objetivos, metodologia de ensino, critérios de avaliação e os principais conteúdos que serão estudados durante o semestre. Também foi apresentada a importância das tecnologias utilizadas no desenvolvimento de aplicações web modernas. :contentReference[oaicite:0]{index=0}

---

# Conteúdos Apresentados

## 1. Versionamento e Deploy
O versionamento é responsável por registrar todas as alterações realizadas em um projeto, permitindo:

- Recuperar versões anteriores;
- Trabalhar em equipe;
- Criar ramificações (branches) para desenvolvimento paralelo.

Também foi apresentada a importância do **Deploy**, processo de publicação de uma aplicação, além de conceitos como:

- GitHub, GitLab e Bitbucket;
- Integração Contínua (CI);
- Entrega Contínua (CD);
- Boas práticas de automação. :contentReference[oaicite:1]{index=1}

---

## 2. Arquitetura de um Site

Antes de iniciar o desenvolvimento de um sistema é necessário realizar:

- Definição do escopo;
- Planejamento da arquitetura;
- Validação das ideias;
- Refinamento da usabilidade (UX/UI);
- Criação de protótipos.

Essas etapas ajudam a desenvolver aplicações mais organizadas e voltadas às necessidades do usuário. :contentReference[oaicite:2]{index=2}

---

## 3. JavaScript (Vanilla JS)

Foi apresentada uma introdução ao JavaScript, destacando que:

- É uma linguagem interpretada;
- É essencial para o desenvolvimento Front-end;
- O Vanilla JavaScript corresponde ao JavaScript puro, sem frameworks.

Seu principal objetivo é adicionar lógica, interatividade e comunicação com servidores em páginas web. :contentReference[oaicite:3]{index=3}

---

## 4. Servidores, Hospedagem e CMS

A aula abordou conceitos relacionados a:

- Hospedagem de sites;
- Sistemas CMS (Content Management System);
- Criação de páginas sem necessidade de programação intensa;
- Instalação de plugins e personalizações. :contentReference[oaicite:4]{index=4}

---

## 5. Website Builders

São plataformas que permitem criar sites rapidamente utilizando modelos prontos.

### Vantagens

- Facilidade de uso;
- Rapidez no desenvolvimento;
- Baixo custo;
- Templates responsivos.

### Limitações

- Pouca flexibilidade;
- Possível perda de desempenho;
- Dificuldade de migração entre plataformas. :contentReference[oaicite:5]{index=5}

---

## 6. Frameworks Front-end

Foi apresentada uma visão geral sobre frameworks modernos, como:

- React;
- Vue;
- Angular.

Também foram introduzidos conceitos importantes:

- Componentização;
- Gerenciamento de estado;
- Rotas;
- Integração com APIs. :contentReference[oaicite:6]{index=6}

---

## 7. Frameworks Back-end

Na parte de Back-end foram apresentados conceitos como:

- Arquitetura MVC;
- APIs REST;
- Integração com bancos de dados;
- Autenticação e segurança.

Esses recursos são fundamentais para o desenvolvimento de aplicações completas. :contentReference[oaicite:7]{index=7}

---

## 8. Banco de Dados NoSQL

Foi introduzido o conceito de bancos de dados NoSQL, caracterizados por:

- Não utilizarem tabelas fixas;
- Possuírem esquemas flexíveis;
- Oferecerem alta escalabilidade para grandes aplicações. :contentReference[oaicite:8]{index=8}

# Importância do Portfólio

O professor destacou que manter um portfólio de projetos permite:

- Demonstrar habilidades práticas;
- Organizar o aprendizado;
- Aumentar as oportunidades de estágio e emprego;
- Evoluir continuamente como desenvolvedor. :contentReference[oaicite:9]{index=9}

---

# Critérios de Avaliação

A nota final será composta por:

- **P1 (25%)** – Prova 1;
- **P2 (25%)** – Prova 2;
- **Projeto + Atividades (50%)**. :contentReference[oaicite:10]{index=10}

---

# Atividade da Aula

Os alunos deverão:

1. Formar grupos de 3 a 5 integrantes;
2. Definir uma proposta de projeto para desenvolver durante o semestre;
3. Criar um repositório no GitHub;
4. Produzir um arquivo **README.md** contendo um resumo da Aula 01;
5. Escolher três sites, identificar as tecnologias utilizadas e representar essa análise no Miro, salvando a imagem no repositório. :contentReference[oaicite:11]{index=11}

# Conclusão

A aula teve como objetivo apresentar a estrutura da disciplina e introduzir os principais conceitos que serão estudados ao longo do semestre. Foram abordados temas fundamentais do desenvolvimento web moderno, como versionamento, deploy, arquitetura de software, JavaScript, frameworks Front-end e Back-end, bancos de dados NoSQL e a importância da construção de um portfólio profissional. Além disso, foram explicados os critérios de avaliação e as atividades iniciais da disciplina. :contentReference[oaicite:12]{index=12}
